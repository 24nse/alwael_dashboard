# مؤسسة الوعل للعقارات والمقاولات

لوحة تحكم إدارية لمؤسسة الوعل للعقارات والمقاولات في المكلا، اليمن.

## 🚀 النشر التلقائي

تم إعداد هذا المشروع للنشر التلقائي على GitHub Pages. عند كل push إلى branch `main` أو `master`، سيتم:

1. ✅ بناء المشروع تلقائياً
2. ✅ نشره على GitHub Pages
3. ✅ إتاحته على الرابط: `https://24nse.github.io/alwael_dashboard/`

### خطوات تفعيل GitHub Pages (مرة واحدة فقط):

1. اذهب إلى إعدادات المستودع على GitHub
2. اختر **Settings** → **Pages**
3. في قسم **Source**، اختر **GitHub Actions**
4. احفظ التغييرات

بعد ذلك، أي تغيير تقوم به سينشر تلقائياً!

## 🛠️ التطوير المحلي

### المتطلبات
- Node.js 18 أو أحدث
- npm أو yarn

### التثبيت والتشغيل

```bash
# تثبيت المكتبات
npm install

# تشغيل السيرفر المحلي
npm run dev

# بناء المشروع للإنتاج
npm run build

# معاينة البناء
npm run preview
```

## 📦 التقنيات المستخدمة

- **React 18** - مكتبة واجهة المستخدم
- **TypeScript** - لغة البرمجة
- **Vite** - أداة البناء
- **Tailwind CSS** - إطار عمل CSS
- **shadcn/ui** - مكتبة المكونات
- **React Router** - التوجيه
- **Lucide React** - الأيقونات
